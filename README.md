# 台灣股市資料擷取 (Stock Collection)

> 建立自動化爬蟲排程擷取台股每日交易、月度營收與季度財報，此為以Github驅動的基本資料庫存。

---

## 📌 專案架構與開發目標

- [x] **1. 股票標的清單與每日數據源研究**
  * 使用 MOPS 每日交易資訊，擷取全部上市（不含權證=ALLBUT0999）／上櫃股票之市場交易資訊。
  * 📅 預定開發項目
    - [x] **每日報價數據**：每日 16:00 前自動擷取個股（外資、投信、自營商）買賣超資訊。
    - [ ] **月營收數據**：每月 10 號（遇假日順延）晚間起自動擷取上市櫃公司月營收，並保留 11～12 號補抓機制。
    - [ ] **季報／單季數據**：依季報公告時程（5/15、8/14、11/14、3/31 前，遇假日順延）或季末月營收公布後，自動擷取單季營收與財報指標。

- [x] **2. 交易時間與日曆模組**
  * 結合 Python `holidays` 套件，自動判斷台灣國定假日與非交易日。
  - [x] * 提供函數簡易判斷最近一個有效交易日，並回傳日期供收盤資料擷取。

- [x] **3. GitHub Actions 排程自動化**
  * 設定每日收盤後（16:00 UTC+8）自動觸發爬蟲與資料消化流程。
  * 設定每日自動從公告訊息中篩選達「注意股票」標準的標的，並提供近一個月 EPS 作為參考資料。

- [x] **4. 原始資料存儲 (Raw Data saving)**
  * **路徑**：`./stockData/`
  * 提供 JSON 格式資料存儲，作為中間資料供確認。（debug mode on）

- [x] **5. MongoDB 寫入 (MongoDB Atlas storage)**
  * 線上儲存資料至 MongoDB Atlas Cluster。

- [x] **6. Discord 線上通知 (Discord Notification)**
  * 將抓到的資料彙整完畢後，傳送到 Discord 進行通知。
  * 測試用頻道：https://discord.gg/sScQvzXjB
  * 目前僅提供每日若有特殊狀況、被要求公開前一個月財務狀況者，推播公司名稱／代號及最近一個月每股盈餘（EPS）。
